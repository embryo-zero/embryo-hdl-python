# Embryo HDL Python

Embryo HDL Python is Embryo-Zero's fork of [Amaranth HDL](https://github.com/amaranth-lang/amaranth) (v0.5.10, commit 4ce62de). It lets people write chips in Python.
It is one of the Embryo chip tools, with Embryo Router (our Freerouting fork) and Embryo PCB (our KiCad fork).

- Our changes live on the `embryo` branch. The original license files (LICENSE.txt) are unchanged.
- Legal notes: LEGAL.md. Dated list of our changes: CHANGES-EMBRYO.md.
